# Susana Rodríguez — Consultora Mary Kay Colombia

Sitio web de **Susana Rodríguez** (Consultora de Belleza Independiente Mary Kay®): landing principal, dosier corporativo de bienestar empresarial y presentación ejecutiva.

## Estructura

| Archivo | Descripción |
| --- | --- |
| `index.html` | Landing principal (TimeWise 3D®, quiz de diagnóstico, FAQ) |
| `dosier-empresarial.html` | Propuesta de bienestar corporativo + calculadora para RRHH |
| `presentacion.html` | Presentación ejecutiva (12 diapositivas, navegación con swipe en móvil) |
| `styles.css` | Estilos compartidos (responsive) |
| `script.js` | Interacciones de la landing (menú móvil, quiz, FAQ, selector de rutina) |
| `script-dosier.js` | Calculadora corporativa y formulario de agendamiento |
| `assets/` | Imágenes optimizadas (JPEG) |
| `sitemap.xml` / `robots.txt` | Archivos de SEO |
| `Propuesta_Bienestar_MaryKay_SusanaRodriguez.pptx` | Presentación descargable |

## Publicación

Todo el contenido se sube a la **raíz** del dominio (`public_html`). No requiere build ni dependencias.

## Optimizaciones aplicadas

- Diseño responsive con breakpoints en 1200, 1024, 768, 480 y 400 px.
- Imágenes recomprimidas (≈ −84 % de peso) con carga diferida.
- Menú móvil accesible, acordeón de FAQ y swipe en la presentación.
- SEO: meta descripciones únicas, `canonical`, Open Graph, `sitemap.xml` y `robots.txt`.
- Enlaces externos con `rel="noopener noreferrer"`.
